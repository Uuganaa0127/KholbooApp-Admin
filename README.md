# Youth Med React admin

React/Vite dashboard for the Youth Med app. Connects to the Express API in
[KholbooApp-Back](https://github.com/Uuganaa0127/KholbooApp-Back).

## Run locally

Use Node.js 22 or newer and npm. First start the backend using its README.
Then, in this repository:

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:5180 and sign in using the admin credentials generated by
the backend setup. No accounts, passwords or backend data are included here.
The development server binds to loopback and proxies `/api` and `/uploads` to
http://127.0.0.1:4100. Port 5180 must be free.

## Dashboard features

- User management and membership status.
- Main courses, subcourses, video uploads, course exams and answer authoring.
- Normal/premium tests, mini-games and surveys.
- Discussion categories and moderation.
- News stories with image upload and publishing controls.
- Bonus coin settings and account adjustments.
- Screening records and learning analytics.
- Read-only published Youth Health membership list.

The Youth Health member list is separate from local app users. Membership
applications do not automatically create shared app login credentials.

## Backend configuration

The default API URL is `/api`. For a separately hosted backend, copy
`.env.example` to `.env` and set `VITE_API_URL` to the backend's HTTPS URL ending
in `/api`. Set the backend `ALLOWED_ORIGINS` to include the admin website origin.
Vite embeds this URL when building; rebuild after changing it. Never put secrets
in `VITE_` variables, which are visible in browser code.

## Tests and production build

```sh
npm test
npm run build
```

Editor tests use mocked API requests and do not change a live backend. GitHub
Actions runs these tests and the build on pushes and pull requests.

Deploy the generated `dist/` directory to a static host. If using the default
relative API URL, configure that host to proxy `/api` and `/uploads` to the
backend: the Vite development proxy is not included in the production build.
`npm run preview` only previews the static build and does not provide an API
proxy. Backend hosting is separate from this frontend repository.
